# AJLink AI — Fix What AI Builds.

Product concept: **AI Builder Survival Kit**. Help a maintainer understand a failure, review a fix, check a release and hand work to the next person with evidence. Target an individual maintaining an AI-assisted Python project first. No claim of existing adoption, saved time, complete security or accepted coding-agent support.

| Stage | Deliverable | Existing or new component | Boundary |
| --- | --- | --- | --- |
| Diagnose | Symptom, evidence, hypotheses, smallest next check | Existing ai-project-rescue | Advisory; skill-host acceptance pending |
| Fix Safely | Changed-contract risks with snapshot/line references | New AI Fix Regression Guard | Static Python subset; no edits or test execution |
| Release Check | Findings, missing/stale gate records, human-review decision | New Safe GitHub Publisher + existing safe-deploy-checklist | No connection, push, visibility change or deployment |
| Handover | Revision, evidence, rollback assumptions, owner and unknowns | [Handover template](HANDOVER.md) | Human-filled; no fabricated completion |

Preserve thai-ai-copy-humanizer as a bilingual writing utility. It is not positioned as a code verifier or required to use either CLI. All three existing skill folders remain unchanged in this phase.

The initial differentiator is inspectable evidence and honest boundaries, not a claim to replace the four researched projects. The regression tool compares supplied Python snapshots; the publisher audits only the supplied file packet and supplied gate records. Neither automatically inventories a real project. Current examples and tests use synthetic data exclusively.

Definition of utility: a new user can run the two local demos without a hosted model, identify the exact rule/evidence, see why publication is blocked, and produce a useful handover. Definition of trust: actual command results, input digests, limitations, original content, valid license, private reporting and explicit release approval.

Non-goals for v0.1.0: automatic fixes, universal regression detection, hosted APIs, private-repository integrations, live deployments, paid distribution, hooks, MCP servers, marketplace installers, or guaranteed agent support. Website work is excluded from this phase.

The milestone is a reviewed v0.1.0 with one reproducible tool walkthrough and accepted installation/behavior on each host claimed in public copy. Local RC remains NO-GO until [release conditions](RELEASE_CHECKLIST.md) pass. Do not weaken gates for a launch date or a star target.
