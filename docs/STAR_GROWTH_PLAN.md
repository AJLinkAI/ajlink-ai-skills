# Organic discovery and Stars

Stars are a secondary signal, not a promised outcome. No baseline users, traffic, installs or Stars have been measured for this unpublished candidate. Do not buy Stars, use bots, arrange star exchanges, reward reports with Stars, scrape contacts or send unsolicited promotional messages.

## Earn discovery through utility

1. Put the two runnable synthetic demos and exact limits at the top of README. Keep candidate/host status visible.
2. After an approved release, use accurate topics and a concise repository description from [GitHub metadata](GITHUB_METADATA.md). Do not add untested-host topics as compatibility claims.
3. Publish one reproducible before/after review showing a removed guard and the same guard restored. Show tool output, not a fabricated customer success story.
4. Answer project issues with minimal fake reproductions and fixes. Invite an optional Star only after a user reports that the kit helped; never make it a condition of support.
5. Submit to relevant community directories only after reading their rules and receiving separate approval to post. Contribute useful upstream bug reports when genuinely reproduced; do not advertise on unrelated issues.

## Proposed measurements, not results

Maintain a manual weekly aggregate after launch: attempted local walkthroughs, successful walkthroughs, host acceptance reports, unresolved install failures by version/OS, useful risk findings confirmed by a reviewer, false positives, repeat contributors and Stars. Use voluntary issue feedback; no telemetry or unique-user tracking is included. Do not infer installs or retention from clone/Star counts.

First learning checkpoint: five consenting walkthroughs, including a new user and a Windows user, with at least one deliberately incomplete release packet. This is a research target, not achieved adoption. Prioritize fixing repeated installation blockers over adding features. Revise positioning if users cannot explain which decision the reports help them make.

Maintain transparent release notes and credit contributors with consent. Never promise virality, a ranking, a Star count or a response SLA the maintainers cannot meet.
