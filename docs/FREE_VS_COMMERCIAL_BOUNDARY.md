# Free and commercial boundary — proposal

The intended open-source kit includes the three original skills, both local review tools, their synthetic fixtures, evaluation criteria, bilingual usage documentation, security fixes and contribution process. They require no AJLink account, license server, API key, hosted inference or paid integration. The current LICENSE is still an unapproved proposal: do not describe this candidate as already legally licensed open source.

Possible future paid work is optional implementation coaching, private training or organization-specific support under a separate agreement. No paid offer, price, availability or support commitment is launched here. Do not withhold basic safety fixes, usable installation instructions or the documented local tool functionality to create an upsell. A final permissive license would allow uses under its terms, including independent commercial reuse; marketing copy cannot quietly remove those rights.

Never include customer adaptations, data or credentials in public contributions. Any future private work needs separate authorization and ownership review. No website, billing system, commercial service or client integration is changed in this phase.
