# ข้อเสนอสัญญาอนุญาตก่อนเผยแพร่

วันที่ตรวจ: 20 ตุลาคม 2026 — ยังไม่มีการอนุมัติหรือเปลี่ยนสัญญาอนุญาต ไฟล์ LICENSE ยังคงเป็นข้อเสนอ ไม่ใช่ข้อความให้สิทธิ์ฉบับที่มีผลใช้บังคับ

| ประเด็น | MIT | Apache-2.0 |
| --- | --- | --- |
| การนำไปใช้ | ใช้ แก้ไข และแจกจ่ายได้ รวมถึงงานเชิงพาณิชย์ โดยต้องคงข้อความลิขสิทธิ์และสัญญาอนุญาต | อนุญาตการใช้งานและแจกจ่ายอย่างกว้างขวาง พร้อมเงื่อนไขการแจ้งสิทธิ์ที่ละเอียดกว่า |
| สิทธิบัตร | ไม่มีข้อให้สิทธิ์สิทธิบัตรโดยชัดแจ้งในตัวข้อความ | มีข้อให้สิทธิ์สิทธิบัตรจากผู้ร่วมพัฒนาตามขอบเขตที่กำหนด และข้อยุติสิทธิ์เมื่อดำเนินคดีสิทธิบัตรตามเงื่อนไข |
| ภาระของผู้แจกจ่าย | ข้อความสั้น อ่านและดูแลได้ง่าย | ต้องแนบสัญญาอนุญาต ระบุไฟล์ที่แก้ไข และรักษาข้อความแจ้งสิทธิ์ที่เกี่ยวข้อง รวมถึง NOTICE หากต้นทางมีและข้อกำหนดนั้นใช้บังคับ |
| เครื่องหมายการค้า | ไม่ควรตีความว่าได้รับสิทธิ์ใช้แบรนด์ | มีข้อสงวนสิทธิ์เครื่องหมายการค้าอย่างชัดเจน |
| ความเหมาะสมกับคลังนี้ | เหมาะกับคำแนะนำ ตัวอย่าง และเครื่องมือตรวจขนาดเล็กที่ต้องการให้คนเริ่มใช้ได้ง่าย | เหมาะเมื่อมีโค้ดหรือผู้ร่วมพัฒนาหลายองค์กร และต้องการเงื่อนไขสิทธิบัตรที่ชัดเจน |

สิ่งที่ต้องอนุมัติ: สัญญาอนุญาตที่เลือก ชื่อผู้ถือสิทธิ์ ปีลิขสิทธิ์ สิทธิ์ของผลงานที่นำเข้า และการใช้ชื่อแบรนด์ จากนั้นจึงแทนที่ LICENSE ด้วยข้อความมาตรฐานฉบับเต็มและตรวจความสอดคล้องของเอกสารอีกครั้ง รายงานนี้ไม่ใช่คำวินิจฉัยทางกฎหมาย
