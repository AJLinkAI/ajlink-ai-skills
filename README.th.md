ก่อนเชื่อว่า AI แก้ปัญหาเสร็จแล้ว ลองตรวจว่าโค้ดเปลี่ยนอะไร มีความเสี่ยงตรงไหน และยังขาดหลักฐานอะไร AJLink มีเครื่องมือ Python แบบอ่านอย่างเดียว 2 ตัว พร้อม skill สองภาษา 3 ตัว ไม่แก้โค้ด ไม่ push ไม่เปลี่ยนสถานะ repository และไม่ปล่อยระบบให้เอง

**สถานะ: v0.1.0-rc.1 ในเครื่อง ยังไม่เผยแพร่ และยังเป็น NO-GO** ต้องยืนยันสัญญาอนุญาต สิทธิ์ GitHub ช่องทางแจ้งปัญหาความปลอดภัย และผลทดสอบบน host ก่อน ไฟล์ LICENSE ยังเป็นข้อเสนอ ไม่ใช่การให้สิทธิ์ใช้งานที่อนุมัติแล้ว

## ลองด้วยข้อมูลจำลอง

จากโฟลเดอร์โครงการ ใช้ Python 3.12 ขึ้นไปที่มีอยู่และได้รับอนุญาต ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้องใช้ API key หรือเปิด agent:

```powershell
python -B tools/regression_guard.py --input examples/regression-before-review.json
python -B tools/regression_guard.py --input examples/regression-after-review.json
python -B tools/safe_github_publisher.py --input examples/publication-blocked.json
```

คำสั่งแรกควรแจ้งว่ามีจุดต้องตรวจและออกด้วยรหัส 1 คำสั่งที่สองไม่พบการเปลี่ยนแปลงที่ตรงกับเกณฑ์ตรวจและออกด้วยรหัส 0 ส่วนคำสั่งที่สามยังไม่ให้ปล่อยงานและออกด้วยรหัส 1 รหัสเหล่านี้เป็นผลที่ตั้งใจให้เกิด ไม่ควรลบข้อเตือนเพื่อให้ผ่าน ดู [วิธีเริ่มใช้](docs/QUICK_START.md), [ขอบเขตเครื่องมือ](docs/TOOLS.md) และ [หลักฐานตัวอย่าง](docs/DEMO_EVIDENCE.md)

## ทดสอบถึงไหนแล้ว

เครื่องมือ Python และตัวอย่างจำลองรันแล้วบน Windows ด้วย Python 3.12.14 ส่วนการค้นพบ skill และพฤติกรรมบน Codex กับ Claude Code ยังไม่ได้ทดสอบ จึง **ยังไม่อ้างว่ารองรับ agent host ใด** Linux และ macOS ยังไม่ได้ทดสอบการรัน ดู [แผนทดสอบ host](docs/HOST_ACCEPTANCE.md) ก่อนใช้ [คู่มือติดตั้ง](docs/INSTALLATION.md)

ส่งรายงานปัญหาด้วยข้อมูลสมมติที่ทำซ้ำได้เท่านั้น ห้ามแนบโค้ดลูกค้า ข้อมูลลับ สำเนาฐานข้อมูล หรือ log ดิบ ดู [การมีส่วนร่วม](CONTRIBUTING.md), [ความปลอดภัย](SECURITY.md), [การเปลี่ยนแปลง](CHANGELOG.md) และ [เงื่อนไขก่อนเผยแพร่](docs/RELEASE_CHECKLIST.md) ไม่มีการเก็บข้อมูลการใช้งาน ซื้อ Stars หรือเผยแพร่อัตโนมัติ
